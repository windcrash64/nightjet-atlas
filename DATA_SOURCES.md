# Data sources, licences and attribution

The **code** in this repository is MIT. That grant does **not** extend to the
data this app fetches or bundles. Every source below keeps its own licence and
terms, and several of them constrain how this project may be deployed.

Read this before deploying anything.

## The constraint that shapes this project

**Transitous — the routing service that makes this app possible — prohibits
commercial use and requires that consuming projects be open source.**

Verbatim from <https://transitous.org/api/>:

> "Due to data source licences and resource prioritisation, commercial use is
> not allowed."

It further requires that projects be open-source with published source code,
that requests carry a `User-Agent` identifying the application with a contact,
and that <https://transitous.org/sources/> is linked in a visible place. It asks
that maintainers be contacted before routing-heavy or multi-user production use.

**This project is therefore MIT-licensed, open source, and non-commercial by
design.** That is not incidental — it is the condition under which the data may
be used at all. If you fork this to build something commercial, you must replace
the Transitous backend with a self-hosted MOTIS instance (MOTIS itself is MIT
and the source datasets carry only their own per-feed licences).

## Live sources — fetched at runtime, never bundled

| Source | Used for | Licence / terms | Key | Attribution |
|---|---|---|---|---|
| [Transitous](https://transitous.org/) (MOTIS v6 `/api/v6/plan`) | All journey routing: rail, night trains, bus, ferry, tram, metro, walking | Non-commercial, open-source projects only; per-feed licences apply | None (identifying User-Agent required) | "Routing by Transitous" + link to [sources](https://transitous.org/sources/) |

### Notes

- **User-Agent.** Transitous's published policy requires an application name,
  version and a means of contact. Empirically only a blank UA is rejected with
  403, but the requirement is contractual, not merely technical — we send a
  real one regardless.
- **No published rate limit.** There is no documented quota, which means there
  is nothing to engineer against and access is revocable at volunteer
  discretion. We cache aggressively and fail honestly rather than hammering it.
- **Fares are not available.** Open transit feeds carry schedules, not retail
  prices. The API exposes `agencyFareUrl` — a link to where a ticket is sold —
  and nothing more. This app therefore never displays a price, and never
  estimates one. See "What this app refuses to do" in the README.

## Bundled data — committed to this repository

| Dataset | File | Licence | Attribution required? |
|---|---|---|---|
| [OurAirports](https://ourairports.com/data/) | `src/data/airports.json` | Public domain (Unlicense) | No (credited anyway) |

`src/data/airports.json` is generated by `scripts/build-airports.mjs`, which
fetches the upstream CSV and filters to airports that have an IATA code, are
marked `scheduled_service=yes`, and are not `type=closed`. That yields **4,132
airports across 234 countries** from 86,003 upstream rows. Regenerate with
`npm run data:airports`.

## Deliberately not used

These were investigated and rejected. Recorded so the reasoning is not lost.

| Source | Why not |
|---|---|
| **OpenFlights `routes.dat`** | Frozen since 2014; upstream states it is "of historical value only". Shipping it as current service would be a lie. |
| **OpenSky Network** | Its Data License Agreement names "integration into a live product, service, or automated system" as requiring a written licence — even for non-profits. Free HTTP 200s are not permission. |
| **Duffel** | Its Services Agreement bans building metasearch on the platform. A comparison tool that does not create orders is contractually prohibited, not merely expensive. |
| **Amadeus Self-Service** | Decommissioned 2026-07-17; the portal and API hosts no longer resolve. Most tutorials online still recommend it. |
| **Google Flights scraping** (`fast-flights` et al.) | `google.com/robots.txt` disallows `/travel/flights/search`, and the technique relies on TLS-fingerprint impersonation. Real prices, but not honestly obtainable. |
| **FOSSGIS public OSRM** | Capped at 1 request/second globally and explicitly prohibited where routing is "a substantial part of an online offering". |
| **OSM tile.openstreetmap.org as a basemap** | The tile CDN returns its "Access blocked" page as `HTTP 200 image/png`, so status codes cannot detect a block. Volunteer infrastructure, withdrawable without notice. We render vector geometry ourselves instead. |
